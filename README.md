## Projetos em destaque

### 🏢 [MS_HR — Sistema de Gestão de Recursos Humanos](https://github.com/Viniciuss27/MS_HR)

Sistema distribuído para gestão de funcionários e processamento de folha de pagamento, desenvolvido com Java 21, Spring Boot e Spring Cloud.

- Microsserviços: Auth, Employee, Payroll, Gateway, Eureka e Config Server.
- Autenticação e autorização com Spring Security e JWT.
- Comunicação assíncrona com Apache Kafka.
- Padrão **Transactional Outbox** para persistência transacional e publicação de eventos com entrega *at-least-once*.
- PostgreSQL, Spring Data JPA, Flyway e MapStruct.
- Testes com JUnit 5 e Mockito.

### 🏦 [MS_Banco — Sistema Bancário](https://github.com/Viniciuss27/MS_Banco)

Sistema bancário que evoluiu de uma aplicação monolítica para uma arquitetura de microsserviços.

- Operações de contas, depósitos, saques e transferências.
- API Gateway, autenticação JWT e descoberta de serviços com Eureka.
- Comunicação assíncrona com Apache Kafka para notificações.
- Publicação de eventos após o commit das transações.
- PostgreSQL, Spring Data JPA e Flyway.
- Testes unitários com JUnit 5 e Mockito.

### 🛒 [MS_E-Commerce — Plataforma de E-Commerce](https://github.com/Viniciuss27/MS_E-Commerce)

Plataforma de e-commerce baseada em microsserviços e comunicação orientada a eventos.

- Serviços de autenticação, clientes, produtos, categorias, pedidos e notificações.
- API Gateway, Eureka e configuração centralizada.
- Processamento de eventos de pedidos com Apache Kafka.
- Fluxo assíncrono de reserva de estoque e notificação.
- Banco de dados PostgreSQL por serviço.
- Segurança com Spring Security e JWT.
- Docker Compose e documentação com Swagger/OpenAPI.

### 📚 [MS_Biblioteca — Sistema de Gestão de Biblioteca](https://github.com/Viniciuss27/MS_Biblioteca)

Sistema de gerenciamento de biblioteca desenvolvido com arquitetura de microsserviços.

- Serviços para usuários, autores, livros e empréstimos.
- Autenticação e autorização com Spring Security e JWT.
- API Gateway, Eureka e Spring Cloud Config.
- Comunicação entre serviços com OpenFeign.
- Resiliência com Resilience4j.
- Persistência com Spring Data JPA e PostgreSQL.

### 🎓 [MS_Escola — Sistema de Gestão Escolar](https://github.com/Viniciuss27/MS_Escola)

Sistema de gestão escolar com microsserviços para administração de alunos, professores, turmas e notas.

- Arquitetura com API Gateway, Eureka e Spring Cloud Config.
- Autenticação OAuth2 Client Credentials e validação de JWT no Gateway.
- Controle de acesso baseado em roles.
- Comunicação entre serviços com OpenFeign.
- Resiliência com Resilience4j e Fallback Factory.
- Banco de dados PostgreSQL isolado por serviço.
- Senhas protegidas com BCrypt e execução com Docker Compose.
